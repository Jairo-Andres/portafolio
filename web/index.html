B

B Línea B · Backend

API de oportunidad de citas

Algunos hospitales públicos publican en datos.gov.co cuántos días espera un paciente por una cita, cada uno con columnas, periodos y formatos distintos. Un ETL en pandas los descarga, limpia y unifica (junto con el archivo Clicsalud 2016–2021) y una API REST los sirve.

  • FastAPI
  • PostgreSQL · Supabase
  • pandas
  • Docker
  • pytest
  • GitHub Actions
  • Render

Plan gratis: la primera petición puede tardar hasta un minuto mientras la API despierta.

D Línea D · Datos

La sala de espera

Un dashboard que consume la API y muestra cuántos días espera un paciente por una cita médica, según lo que publica cada hospital: turnero, relojes, una silla por cada día de espera y gráficos explorables, sin sacar conclusiones que los datos no sostienen.

Radar .gov.co

Una auditoría semanal y automática de 30 portales públicos colombianos: accesibilidad (WCAG 2.1 AA), versión móvil, rendimiento y buenas prácticas, publicada como ranking. Solo tráfico de visitante normal: pocas páginas por sitio, con pausas y respetando robots.txt.

BQ

BQ Estación de transbordo · Full-stack

MiTiendaW

Una plataforma para que un emprendimiento cree su catálogo con link propio y reciba los pedidos armados en WhatsApp: el cliente no se registra ni paga en la web. El vendedor administra su tienda, productos, fotos, stock y ventas, y el administrador aprueba o suspende tiendas.

Aquí se cruzan las líneas B y Q: el backend vive en la base de datos (Supabase con RLS en todas las tablas) y cada regla de seguridad tiene una prueba que intenta romperla.

  • Next.js
  • TypeScript
  • Supabase · Postgres · RLS
  • Tailwind CSS
  • Zod
  • Vitest
  • Playwright + axe
  • GitHub Actions
  • Vercel

G Línea G · Juego en tiempo real

La mina sin fondo

En línea

Excava, vende, mejora y baja más hondo.

Un juego de minería para celular y PC con tres partes: Magnate, un tycoon donde pozos, ascensor y transporte llevan el mineral al almacén; Rieles de la Mina, carreras de vagonetas por niveles con taller de mejoras; y Carrera versus, la misma pista para 2 a 4 jugadores en línea.

La lógica del juego es pura y determinista (semillas, física a 60 Hz) y está separada del dibujo: así dos jugadores en versus generan el mismo mapa. Todos los gráficos se dibujan con código. Sin servidor autoritativo: es para jugar con amigos, no para un ranking competitivo.

3D Línea 3D · Cooperativo multijugador

TrailMates

Beta en desarrollo

Off-road en equipo: nadie llega solo.

Un juego de conducción off-road en 3D para hasta 4 jugadores. Se crea una sala, se comparte un código de 5 letras y se cruzan juntos valles, montañas nevadas y pantanos: bajarse a empujar, remolcar con el cabestrante, reparar e ir de pasajero.

Todavía está en desarrollo, así que puede cambiar o fallar. El anfitrión simula la física (Rapier en WASM, paso fijo a 60 Hz) y el servidor solo reenvía mensajes; los invitados no descargan la física. En las pruebas, 4 navegadores quedan sincronizados a menos de 0,5 m. Arte y sonido generados por código. Los 72 FPS son el tope de la pantalla de prueba (RTX 3050).

Las tres rutas

B Línea B · Backend

API de oportunidad de citas

Algunos hospitales públicos publican en datos.gov.co cuántos días espera un paciente por una cita, cada uno con columnas, periodos y formatos distintos. Un ETL en pandas los descarga, limpia y unifica (junto con el archivo Clicsalud 2016–2021) y una API REST los sirve.

  • FastAPI
  • PostgreSQL · Supabase
  • pandas
  • Docker
  • pytest
  • GitHub Actions
  • Render

Plan gratis: la primera petición puede tardar hasta un minuto mientras la API despierta.

D Línea D · Datos

La sala de espera

Un dashboard que consume la API y muestra cuántos días espera un paciente por una cita médica, según lo que publica cada hospital: turnero, relojes, una silla por cada día de espera y gráficos explorables, sin sacar conclusiones que los datos no sostienen.

  • React
  • Vite
  • Tailwind CSS
  • Vitest
  • Vercel

Q Línea Q · QA

Radar .gov.co

Una auditoría semanal y automática de 30 portales públicos colombianos: accesibilidad (WCAG 2.1 AA), versión móvil, rendimiento y buenas prácticas, publicada como ranking. Solo tráfico de visitante normal: pocas páginas por sitio, con pausas y respetando robots.txt.

  • Python
  • Playwright
  • axe-core
  • Lighthouse
  • pytest
  • GitHub Actions
  • Vercel
